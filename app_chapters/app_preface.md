# Preface

In this part of the book we will introduce several very common topic encountered in numerical analysis.
All of the code examples are available to be copied from the code blocks, but is also stored in the [codeberg reposity](https://codeberg.org/ominusliticus/numath).
These sections are still in flux, and will be rearrange/expanded from knowledge that the authors gain and/or issues open into the GitHub repository for this book or the codeberg repository for the code.
We emphasize that this is not a replacement for more formal treatments of the issues at hand.
In particular, we rarely, if ever, discuss error analysis or convergence properties.
Where possible, we will provide references that were helpful for us to understand the material or reference that treat the material more formally.
